# Harbor

*Code name.* Keep the device you love — we keep it safe.

Harbor lets a family member protect an aging parent's own iPhone or Windows PC from scams and accidental breakage, using enterprise device-management under the hood and a simple, reassuring experience on top. It protects; it never watches.

Status: early design → starting implementation. See [`docs/`](docs/) for the product and architecture decisions, and [`CLAUDE.md`](CLAUDE.md) for the working rules.
